## 为什么

网页适合扫一眼。侧栏、广告、字号和分页都在打断阅读。Page2Reading 是一个 Chrome 扩展：在文章页导出 PDF，只留下正文。

英文文章可以导出原文，也可以导出中英对照。译文按中文的说法来写，术语就地解释。中文文章导出原文 PDF，重新整理结构、字体、间距、代码、图片和分页。

本仓库是产品介绍页。打开 `index.html` 即可预览。

## 用法

在文章页打开扩展，选择导出。

- **原文 PDF**：保留原文，重新排版。
- **中英对照 PDF**：英文在上，中文在下，图表留在原处。

## 翻译

同一句，两种中文。

> A cache keepalive is the one optimization every agent builder agrees on, and almost everyone runs it at the wrong setting.

机械翻译：缓存保持活动是每个代理构建者都认同的优化措施，但几乎每个人都使用了错误的设置。

Page2Reading：缓存保活（cache keepalive，就是隔一段时间给缓存发一次请求，别让它过期）是所有做 agent（智能体，那种能自己调工具、多步骤干活的 AI 程序）的人都认同的优化手段——但几乎所有人都把参数设错了。
